# Expense Tracker API

Backend for tracking expenses. Work in progress.

## Endpoints

| Method | URL | What it does | Success | Errors |
| --- | --- | --- | --- | --- |
| POST | `/expenses` | Create an expense. | 201 | 400 or 422 (invalid body) |
| GET | `/expenses` | List expenses. | 200 | None |
| GET | `/expenses/:id` | Get one expense. | 200 | 404 (not found) |
| PUT | `/expenses/:id` | Replace an expense. | 200 | 400 or 422 (invalid body), 404 (not found) |
| DELETE | `/expenses/:id` | Delete an expense. | 204 | 404 (not found) |
| POST | `/categories` | Create a category. | 201 | 400 or 422 (invalid body), 409 (category name already exists) |
| GET | `/categories` | List categories. | 200 | None |
| GET | `/categories/:id` | Get one category. | 200 | 404 (not found) |
| PUT | `/categories/:id` | Replace a category. | 200 | 400 or 422 (invalid body), 404 (not found), 409 (category name already exists) |
| DELETE | `/categories/:id` | Delete a category. | 204 | 404 (not found) |

### Expense list query params

- `month=YYYY-MM` filters expenses to a calendar month, such as `month=2026-10`.
- `categoryId=3` filters expenses to the specified category ID.

### Data shapes and required fields

- **Expense:** `id` (number, generated by the API), `amount` (number), `description` (string), `date` (ISO 8601 date string, `YYYY-MM-DD`), `categoryId` (number).
  - **Required on POST:** `amount`, `description`, `date`, and `categoryId`. The API generates `id`.
- **Category:** `id` (number, generated by the API), `name` (string).
  - **Required on POST:** `name`. The API generates `id`.
